\begin{abstract}
El presente documento constituye la especificación técnica y de ingeniería de software para el desarrollo del sistema móvil \textbf{FitTracker}. Diseñado bajo un enfoque \textit{Local-First} y arquitectura modular \textit{Clean Architecture}, FitTracker automatiza la gestión de entrenamientos de fuerza mediante un motor de sobrecarga progresiva basado en formulación matemática de estimación de 1RM ($1Repetition Maximum$) y autorregulación por RPE/RIR. Se detalla la especificación de requerimientos (SRS), casos de uso UML, diseño de base de datos SQLite y el modelo algorítmico de progresión.
\end{abstract}
