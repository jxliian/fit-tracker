\begin{abstract}
This document serves as the formal software engineering specification for the mobile system \textbf{FitTracker}. Engineered under a \textit{Local-First} paradigm and modular \textit{Clean Architecture}, FitTracker automates resistance training management using an adaptive progressive overload engine based on mathematical 1RM ($1Repetition Maximum$) estimation formulas and RPE/RIR autoregulation. It provides the Software Requirements Specification (SRS), UML use cases, SQLite database design, and the progressive algorithm mathematical model.
\end{abstract}
